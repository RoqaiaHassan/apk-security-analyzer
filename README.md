<h1 align="center">🛡️ محلّل أمان تطبيقات أندرويد والتشفير</h1>
<p align="center">Mobile Security &amp; Cryptographic Vulnerability Analyzer</p>

مشروع ويب تعليمي لفحص تطبيقات أندرويد بصيغة (`.apk`) فحصًا ساكنًا (Static Security Analysis). يبحث عن مؤشرات لمشكلات التشفير والأسرار المضمّنة، ويعرض درجة أمان تقديرية ونتائج الفحص، مع إمكانية إنشاء تقارير PDF واستخدام مختبر تفاعلي لتجربة التشفير.

<blockquote><strong>ملاحظة:</strong> هذا المشروع أداة مساعدة تعليمية للفحص الساكن، وليس بديلًا عن اختبار الاختراق أو المراجعة الأمنية المتخصصة.</blockquote>

<h2>المميزات (Features)</h2>

- فحص ملفات APK: استخراج الملفات دون تشغيل التطبيق، وحساب بصمات (`SHA-256`, `SHA-1`, `MD5`) وقراءة معلومات من `AndroidManifest.xml`.
- تحليل التشفير: البحث عن مؤشرات لاستخدام `AES/ECB` و`DES` و`3DES` و`MD5` و`SHA-1`، إضافة إلى أنماط لمفاتيح RSA الضعيفة و`java.util.Random` وIV ثابت.
- كشف الأسرار: البحث عن مؤشرات لمفاتيح تشفير وكلمات مرور ومفاتيح Google وAWS ورموز JWT المضمّنة. تُخفى أجزاء من قيمة السر في الدليل المكتشف.
- تحليل الشبكة: رصد عناوين `HTTP` ومؤشرات على تجاوز التحقق من شهادات SSL/TLS.
- قواعد الكشف ودرجة الأمان: تطبيق قواعد JSON وحساب درجة تقديرية اعتمادًا على النتائج المكتشفة.
- مختبر التشفير (Crypto Lab): تجربة خوارزميات قيصر وفيجينير والاستبدال الأحادي وAES و3DES ودوال التجزئة من المتصفح.
- السجل والتقارير: حفظ الفحوصات في SQLite وإنشاء تقرير أمني بصيغة PDF عند الطلب.

يعتمد التحليل على أنماط نصية مستخرجة من ملفات التطبيق؛ لذلك قد لا يكتشف كل سلوك أو ثغرة، وقد تحتاج بعض النتائج إلى مراجعة يدوية.

<h2>المعمارية (Architecture)</h2>

```text
.
├── backend/                 # خادم FastAPI ومحركات التحليل
│   ├── api/                 # واجهات البرمجة (Endpoints) للرفع والمختبر
│   ├── analyzers/           # محللات APK وDEX وManifest والتشفير والأسرار والشبكة
│   ├── crypto/              # خوارزميات المختبر وحساب درجات الأمان
│   ├── detectors/           # محرك تطبيق قواعد الكشف
│   └── reports/             # محرك إنشاء تقارير PDF
├── frontend/                # واجهات المستخدم (HTML, CSS, JavaScript)
├── rules/                   # قواعد الكشف المصنفة بصيغة JSON
├── tests/                   # الاختبارات ومولّد ملفات APK التجريبية
├── uploads/                 # المجلد المؤقت لرفع الملفات
├── main.py                  # مدخل تشغيل بديل للخادم
└── requirements.txt         # حزم واعتمادات Python

```

تعتمد الخلفية على Python وFastAPI، وتستخدم SQLite لحفظ بيانات الفحوصات وReportLab لإنشاء ملفات PDF. الواجهة مبنية باستخدام HTML وCSS وJavaScript.

<h2>التثبيت والتشغيل (Installation &amp; Run)</h2>

أنشئ بيئة افتراضية وثبّت الحزم المطلوبة من مجلد المشروع:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

على Linux أو macOS، استخدم أمر التفعيل التالي:

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
```

شغّل الخادم:

```bash
python backend/main.py
```

ثم افتح [http://127.0.0.1:8000](http://127.0.0.1:8000). ويمكن فتح توثيق API التفاعلي على [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

أو شغّل التطبيق مباشرة باستخدام Uvicorn:

```bash
uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```

<h2>الاختبار والجودة (Testing)</h2>

```bash
python tests/test_samples.py

python -m unittest discover -s tests -v
```

- ينشئ مولّد العينات ملفات APK اصطناعية داخل `tests/sample_apks/`.
- تشمل الاختبارات الحالية خوارزميات التشفير الكلاسيكية وفحص عينة APK عند توليدها.

<h2>الملفات والبيانات (Project Files)</h2>

| الملف / المجلد | الوصف |
| --- | --- |
| `analyzer.db` | قاعدة SQLite التي تُحفظ فيها نتائج الفحص وسجله. |
| `uploads/` | ملفات APK المرفوعة وملفات الاستخراج المؤقتة أثناء التحليل. |
| `reports_output/` | ملفات PDF التي تُنشأ عند طلب التقرير. |
| `rules/` | قواعد الكشف بصيغة JSON. |
| `tests/sample_apks/` | ملفات APK الاصطناعية بعد تشغيل مولّد العينات. |

<h2>ملاحظات مهمة (Notes)</h2>

- الخصوصية: تعامل مع ملفات APK والتقارير على أنها بيانات حساسة.
- النشر: شغّل الخادم محليًا أو في بيئة موثوقة. لا تعرضه للإنترنت مباشرة دون إضافة المصادقة وضوابط الحماية المناسبة.
- المساهمة: عند اقتراح قاعدة أو تعديل، أرفق اختبارًا أو مثالًا اصطناعيًا، ولا ترفع مفاتيح أو بيانات حقيقية حساسة.
